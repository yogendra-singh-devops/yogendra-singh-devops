## 🚀 Key Projects & Architecture Blueprints

### 1. 🌐 Enterprise Hub-and-Spoke Networking
- **Central Connectivity:** Hub VNet housing Azure Firewall Premium / NVA for deep packet inspection and centralized internet egress (`0.0.0.0/0`).
- **Secure Isolation:** Spoke VNets for application workloads and shared CI/CD build agents connected via VNet Peering with User Defined Routes (UDR).
- **Private Access:** PaaS resources (Azure SQL, Key Vault, Blob Storage) secured using Private Endpoints with centralized Private DNS Zones.
- **Perimeter Security:** Azure Application Gateway / Front Door configured with Web Application Firewall (WAF) policies.

---

### 2. 🏗️ Automated Terraform Landing Zone & CI/CD Pipeline
- **Modular IaC:** Parameterized, reusable Terraform modules versioned with semantic releases.
- **Remote State Locking:** State stored in private Azure Blob Storage with blob lease locking and CMK encryption.
- **Shift-Left Security Gate:** Automated PR pipeline executing:
  1. `terraform fmt` & `tflint` (Code standard & linting)
  2. `Checkov` & `Trivy` (Security & vulnerability scanning)
  3. `Infracost` (Cost estimation before deployment)
  4. Production manual approval gate ➔ `terraform apply`
- **Drift Detection:** Nightly automated pipeline detecting unauthorized manual configuration drift.

---

### 3. 📦 100+ Workload Enterprise Cloud Migration Playbook
- **Phase 1: Discovery & Dependency Mapping** — Cataloging inventory and inter-app dependencies using Azure Migrate.
- **Phase 2: Compatibility & TCO Assessment** — Sizing compute, bandwidth, and estimating cloud ROI.
- **Phase 3: Landing Zone Readiness** — ExpressRoute/VPN setup, subnet allocation, and security baselines.
- **Phase 4: Cutover Execution** — Database replication sync, DNS TTL step-down, and scheduled downtime window.
- **Phase 5: Hypercare (2-4 Weeks)** — 24/7 war room telemetry monitoring, alert tuning, and post-migration optimization.

---

### 4. 🛡️ Multi-Layer Defense-in-Depth Security
- **Identity Level:** Microsoft Entra ID, Conditional Access, Multi-Factor Authentication (MFA), and PIM Just-In-Time access.
- **Network Level:** Micro-segmentation with Network Security Groups (NSGs), Application Security Groups (ASGs), and DDoS Protection.
- **Governance Level:** Automated Azure Policy enforcement with Audit/Deny effects and compliance reporting.
- **Compute Level:** Microsoft Defender for Servers, automated OS patch management, and Customer-Managed Key (CMK) disk encryption.

---

### 5. 💰 FinOps & Cloud Cost Optimization
- **Idle Asset Cleanup:** Automated scripts detecting and terminating unattached disks, orphaned snapshots, and unused public IPs.
- **Rightsizing:** Analyzing 30-day P95 utilization metrics to downsize over-provisioned VMs.
- **Commitment Plans:** Leveraging 1-year and 3-year Azure Reserved Instances and Savings Plans for steady baselines.
- **Auto-Scheduling:** Automating stop/start schedules for non-production environments to save up to 60% on compute.
- **Log Tuning:** Configuring Data Collection Rules (DCR) to filter noisy diagnostic logs and reduce Log Analytics ingestion costs.

---

### 6. 💾 High Availability & Disaster Recovery (BCP)
- **Data Redundancy:** Deploying Zone-Redundant (ZRS) and Geo-Redundant (GRS) storage to prevent data loss.
- **Compute Resiliency:** Utilizing Virtual Machine Scale Sets (VMSS) across multiple Azure Availability Zones.
- **RTO & RPO Adherence:** Defining strict Recovery Time Objectives (RTO) and Recovery Point Objectives (RPO) backed by Azure Site Recovery (ASR) replication drills.
