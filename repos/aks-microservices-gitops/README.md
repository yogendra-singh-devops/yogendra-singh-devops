## 📌 Features
- **Production Helm Packaging:** Fully parameterized Helm charts with Pod Anti-Affinity across Availability Zones.
- **Horizontal Pod Autoscaling (HPA):** Dynamic scaling between 3 to 12 replicas based on real-time CPU & Memory saturation.
- **Azure Workload Identity:** Direct passwordless authentication from pods to Azure Key Vault & Storage Accounts via Entra ID.
- **Ingress & TLS Automation:** NGINX Ingress Controller paired with `cert-manager` for automatic Let's Encrypt TLS certificate lifecycle management.
- **Prometheus & Grafana Observability:** Custom scrape annotations for instant telemetry ingestion.
