## 📌 Key Capabilities
- **Orphaned Disk Sweeper:** Python script auditing and purging unattached managed disks and obsolete snapshots.
- **Non-Prod Auto-Scheduler:** PowerShell Azure Runbook powering automatic stop/start of Dev and UAT VMs outside business hours (delivering up to 60% monthly savings).
- **Tag Enforcement Policies:** Azure Policy JSON definitions enforcing mandatory CostCenter, Owner, and Environment tags.
- **Log Analytics Ingestion Tuner:** Optimizing ingestion tables and setting retention windows via Data Collection Rules (DCR).
